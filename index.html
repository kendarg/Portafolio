Proyectos Destacados
Juego de Memoria

Este proyecto consiste en un juego de memoria desarrollado en Java utilizando la biblioteca Swing.
El objetivo es que el jugador encuentre las parejas correctas entre imágenes de animales y sus nombres en inglés. Cada pareja está compuesta por:
- Una imagen del animal.
- El nombre del animal en inglés.
- El juego registra el tiempo empleado por el usuario y muestra un mensaje de felicitación cuando se encuentran todas las parejas.

Gestor de Tareas

Aplicación web para gestionar tareas de forma sencilla mediante una interfaz interactiva. Permite abrir un formulario para registrar nuevas tareas, validar la información ingresada y mostrar una notificación cuando la tarea ha sido agregada correctamente.
El proyecto utiliza JavaScript, Bootstrap y SweetAlert2 para construir la interfaz y las ventanas modales.
La estructura visual incluye una sección de tareas, notas adicionales y diferentes niveles de importancia.

Mundo Laptop

MundoLaptop es un proyecto de E-Commerce especializado en la venta de laptops, diseñado para ofrecer una experiencia de compra moderna y organizada.
La plataforma contempla productos nuevos, Open Box y usados, además de diferentes marcas y categorías de equipos.
El proyecto también incluye una vista administrativa para gestionar el inventario y agregar o eliminar productos.
